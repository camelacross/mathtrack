# MathTrack

一个无需登录、无需后端的考研数学真题错题管理 Web 应用。使用 React、TypeScript 和 Vite，数据保存在当前浏览器的 `localStorage` 中，不连接数据库、付费 API 或云端账户。

## 功能

- **学习概览**：错题总数、待复习数量、掌握率、各科目分布、知识点错题排名和年份统计；无记录时展示空状态。
- **我的错题本**：新增、编辑、删除错题；按关键词、年份、科目、知识点和掌握状态组合筛选。
- **复习计划**：列出未掌握、巩固中或复做日期已到期的题目，支持更新掌握状态。
- **数据管理**：JSON 备份导出、导入前校验与预览、合并导入、演示数据管理和本地原始备份导出。
- **中文响应式界面**：适配桌面与手机，表单提供字段标签和校验反馈，支持键盘操作。

每条错题包含真题年份、题号、科目、知识点标签、错误原因、掌握状态、复做日期和备注。科目为高等数学、线性代数、概率论与数理统计；掌握状态为未掌握、巩固中、已掌握。

首次打开时没有任何记录。可在学习概览或数据管理中主动载入 6 条**虚构演示数据**。样例不包含真实题目内容或个人数据，均标记为「演示」。统计会包含这些记录，页面会明确提示；可逐条删除，也可在数据管理中一键删除全部演示记录。编辑演示记录不会去掉其演示标记，重复载入会跳过已有同 ID 样例。

## 安装与运行

需要 **Node.js 22.12.0 或更高版本**及 npm。首次安装依赖需要访问 npm registry；应用运行时不请求外部 API。

```bash
npm ci
npm run dev
```

访问终端中 Vite 显示的地址，通常为 `http://localhost:5173`。开发服务器绑定 `0.0.0.0`，便于在允许局域网访问的环境下用手机调试；手机浏览器拥有独立的数据存储。

```bash
# 执行自动化测试一次
npm test

# 开发时持续运行相关测试
npm run test:watch

# TypeScript 类型检查
npm run typecheck

# 类型检查并生成生产构建
npm run build

# 本地预览生产构建；先执行 build
npm run preview
```

构建产物位于 `dist/`。生产预览通常为 `http://localhost:4173`。请通过 HTTP 服务访问构建产物，不要直接双击 HTML 文件。应用使用 hash 导航，静态托管时无需为页面路由设置后端接口。开发地址、预览地址及托管地址的来源不同，数据互不共享。

## 复习与统计规则

- 状态为「未掌握」或「巩固中」的题目都会进入复习列表，即使没有复做日期或日期尚未到来。
- 已掌握题目如果设置了今天或更早的复做日期，也会进入复习列表。到期题目优先排列，其后按复做日期、年份和题号排序。
- 在复习页面标记「已掌握」表示完成本轮复习，应用同时清除复做日期。可通过编辑题目安排下一次复做；仅在编辑表单中修改掌握状态不会自动清除手动设置的日期。
- 日期以当前设备的本地时区判断，保存格式为 `YYYY-MM-DD`；创建及更新时间使用 ISO 时间戳。
- 掌握率为已掌握记录数除以总记录数，四舍五入为整数百分比；没有记录时为 `0%`。
- 知识点排名统计包含该标签的题目数量。同一题的重复标签只计一次，一道题可计入多个知识点。

## JSON 数据格式

导入文件必须是版本为 `1` 的完整对象。根对象的 `version`、`exportedAt`、`questions` 和每条题目的下列字段均必须存在。下面是一条**虚构示例**，可作为格式参考：

```json
{
  "version": 1,
  "exportedAt": "2026-10-26T09:00:00.000Z",
  "questions": [
    {
      "id": "example-calculus-001",
      "year": 2025,
      "questionNumber": "17",
      "subject": "高等数学",
      "tags": ["定积分", "换元积分"],
      "errorReason": "换元后遗漏积分上下限的转换。",
      "status": "未掌握",
      "reviewDate": "2026-10-28",
      "notes": "虚构演示记录，仅用于说明格式，不对应真实真题。",
      "isDemo": true,
      "createdAt": "2026-10-26T08:30:00.000Z",
      "updatedAt": "2026-10-26T08:30:00.000Z"
    }
  ]
}
```

| 字段                     | 约束                                              |
| ------------------------ | ------------------------------------------------- |
| `version`                | 当前仅支持数字 `1`                                |
| `exportedAt`             | 有效 ISO 时间戳                                   |
| `questions`              | 题目数组，允许空数组                              |
| `id`                     | 非空字符串，最多 100 字符；同一导入文件中不可重复 |
| `year`                   | 1987–2100 的整数                                  |
| `questionNumber`         | 非空字符串，最多 64 字符，可写 `17（2）` 等题号   |
| `subject`                | `高等数学`、`线性代数`、`概率论与数理统计` 之一   |
| `tags`                   | 最多 20 个非空标签，每个最多 40 字符；允许空数组  |
| `errorReason`            | 非空字符串，最多 2,000 字符                       |
| `status`                 | `未掌握`、`巩固中`、`已掌握` 之一                 |
| `reviewDate`             | 真实有效的 `YYYY-MM-DD` 日期，或 `null`           |
| `notes`                  | 字符串，最多 10,000 字符；允许空字符串            |
| `isDemo`                 | 布尔值，用于识别和删除演示记录                    |
| `createdAt`、`updatedAt` | 有效 ISO 时间戳                                   |

题号、ID、标签和错误原因会去除首尾空白，重复标签会合并，未知字段不进入应用状态。导入文件中任何一条记录校验失败，整个文件都不会导入。日期会检查真实日历日期，例如 `2026-02-30` 会被拒绝。

导入分为选择文件、完整校验、预览新增与跳过数量、确认合并四步。合并时保留已有 ID 的记录，不用导入内容覆盖它们；不同 ID 即使年份和题号相同，也会视为不同记录。取消预览不会改变数据。

单个导入文件不超过 **5 MiB**；合并后的总记录数不超过 **10,000 条**，持久化后的完整 JSON 也必须满足校验大小限制。浏览器实际的 `localStorage` 配额可能更低，因此这些上限不代表一定能存满。存储失败时会显示错误，并保留原有记录及当前已保存的界面状态。

## 持久化、备份与恢复

存储键为 `mathtrack.v1`，内容采用上述完整 JSON 格式。每次变更都先校验并写入本地存储，成功后才更新界面。读取到损坏数据时不会自动清空、补入样例或覆盖原始内容，而是显示错误并暂停写入。写入前也会检查存储是否被其他标签页改变，发现变化时要求刷新，避免用已知过期的快照覆盖新记录。

建议定期使用「数据管理 → 导出 JSON」，并将文件保存在可靠位置。导出备份包含演示标记和全部题目字段；在其他浏览器或设备中可手动导入。

如果出现本地数据校验失败，请按以下顺序恢复：

1. 进入「数据管理」，选择「导出本地原始备份」。这会下载 `.txt` 文件，保留未经修改的存储内容。**先确认文件确实已下载并保留副本，再进行任何重置。**
2. 在副本中按照上面的格式修复错误，并另存为 UTF-8 编码的 `.json` 文件；也可以使用此前已导出的正常 JSON 备份。不要覆盖唯一的原始备份。
3. 在「导入记录」中选择修复后的文件，确认能显示「校验通过」及合理的记录数量。此时仍处于写入保护状态，先不要确认导入。
4. 确定备份可恢复后，在当前 MathTrack 页面的浏览器开发者工具中找到该站点的 Local Storage，仅删除 `mathtrack.v1` 这一项。也可在该页面的控制台执行下面的命令。**这一步会删除当前站点的本地记录；没有可恢复的备份时不要执行。**

   ```js
   localStorage.removeItem("mathtrack.v1");
   location.reload();
   ```

5. 刷新后应用回到空状态，再通过「数据管理」选择已验证的备份，检查预览并确认导入。

不要为恢复本应用而清除整个浏览器或其他网站的数据。如果浏览器禁止存储或下载，需先调整该站点的权限；若无法读取原始数据且没有有效备份，应用无法保证恢复记录。

## 已知限制

- 数据只属于当前浏览器配置和站点来源（协议、主机及端口），不自动跨设备、跨浏览器或跨来源同步，也没有云端备份。
- 清除站点数据、浏览器重置或隐私模式结束可能使记录丢失。应用不加密浏览器中的记录，不适合存放敏感个人信息。
- 目前管理题目索引、错因和复习记录，不提供真实真题库、图片附件、题目正文编辑器或 LaTeX 渲染。
- 多标签页检测可拦截已发现的外部变更，但 `localStorage` 不提供跨标签页事务；建议在一个标签页中编辑。
- 复习安排由用户维护，不包含后台通知、系统日历同步或自动间隔重复算法。
- 未实现服务工作线程离线缓存；开发与首次加载仍需运行本地服务器或访问静态托管站点。
